## Session Context (Zed MCP)

You can manage Zed editor settings, themes, extensions, projects, and agent configuration.

**Before starting work:**
1. Check current state: `zed_get_settings()`, `zed_list_extensions()`
2. Check what's available: `zed_list_themes()`, `zed_get_recent_projects()`

**At end of work:**
- Confirm changes took effect by re-reading settings where relevant
